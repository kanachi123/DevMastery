## идея
**Любой объект рекурсивно делится на две части, пока каждая часть не станет достаточно простой.**


```
разделение карт;
определение видимости (Painter's Algorithm);
трассировка лучей;
столкновения объектов;
хранение больших сцен;
генерация уровней;
разбиение строк, массивов и данных (твой пример)

```

```

             World
            /     \
        Front      Back
        /  \        / \
      A     B      C   D


```
