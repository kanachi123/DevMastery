### Лексема  

язык программирования имеет собственные минимальные смысловые единицы 
такие как символы,идентификаторы,ключевые слова операторы,разделители и литералы

На уровне исходного текста можно выделить отдельные символы, а из последовательностей символов образуются лексемы — элементы, распознаваемые правилами конкретного языка

#### примеры
```C

printf() // это лексема ->идентификатор
int //это лексема ->ключевое слово

5 //это лексема -> литерал
& // это лексема взятия адреса -> оператор


грубо говоря в философии это форма


```

```
символ → материал
лексема → форма
синтаксическая конструкция → организованная структура
программа → целостная система


Например, в естественном языке:

к + о + т → «кот»

В программировании:

i + n + t → int
```

### Бритва Оккама

**это методологический принцип, сформулированный английским монахом-францисканцем и философом Уильямом из Оккама (ок.  1285–1347), который гласит: «Не следует множить сущее без необходимости»**

### Погре́шность измере́ния  
разность между измеренным значением величины, и опорным значением величины  

представим ты измерил число пи через полином получил где то 3,141596 например

ты используешь его в численных методах,но это апроксимация какого то выпуклого многоугольника

модель становится сложным в вычесляениях ошибки накапливаются это особенно видно в типах флоут или когда ты отбрасываешь числа после запятой

и в итоге модель ломается и появляются глюки и баги  

**другой пример**  

у тебя уравнение мячика ускорение отрицательное,начальная скорость положительная,нужно например нарисовать линию на максимуме высоты мячика,ускорение равное -0,0001(шаг по численным методам)

что будет в итоге может быть так что начальная скорость такая при котором добавив дискретное значение сразу ты прыгнешь с отрицательного на положительное значение скорости то есть ты неимеешь условие нуля

прична простая дискретизация функцию делает дискретной после которого она уже не непрерывная

здесь можно использовать либо условие с округлением,либо проверить знак если знак поменялся нарисовать,или другие методы зависимо сейчас утрирую

например вычитваешь очень близкие числа тогда относительная погрешнсоть огромная и это создает проблемы это все подводка к апроксимации
