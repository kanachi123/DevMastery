### Лексема  

язык программирования имеет собственные минимальные смысловые единицы 
такие как символы,идентификаторы,ключевые слова операторы,разделители и литералы

На уровне исходного текста можно выделить отдельные символы, а из последовательностей символов образуются лексемы — элементы, распознаваемые правилами конкретного языка

#### примеры
```C

printf() // это лексема ->идентификатор
int //это лексема ->ключевое слово

5 //это лексема -> литерал
& // это лексема взятия адреса -> оператор


грубо говоря в философии это форма


```

```
символ → материал
лексема → форма
синтаксическая конструкция → организованная структура
программа → целостная система


Например, в естественном языке:

к + о + т → «кот»

В программировании:

i + n + t → int
```
