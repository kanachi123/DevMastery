## сейчас определим что все это такое  

Concern означает с английского ответственность 

SoC переводится,как разделение ответственности  

например

```cpp

не SoC

//стороняя библиотека с объертками нашего класса, который дает интерфейс к разным его методам
#include <human_tools.hpp>
#include <windows.h>//доступ к sleep из winapi

...


void Human(){

    human.eat(apple);
    human.work(hours);
    Sleep(500);
    child.eat(apple);
    child.play(Fortnite);

}
```
## этот код говно
```
 потому что процедура человек,делает много штук,так еще и вызывает методы другого класса не связанного с ним,но которая наследуется от нее

это ребенок child
```

## теперь правильный код

юудем использовать наследование и описание методов либо стурктуры либо класса а потом вызвов

```cpp

class Subject{
    ...
    public:
    Subject() = default;
    void eat(const string& food);
    ...

}

class Human : public Subject{

    Human() = default;
    
    void work(const size_t& hours);
    ...
}
class Child : public Subject{

    Child() = default;

    void play(const string& GameName){};
    
}


```  

## В чем суть 

**разделение обязанностей,если ты программист,ты не работаешь таксистом**

```
если ты даже умеешь готовить еду,ты не делаешь это на работе,если твоя роль на работе быть прогаммистом,это не значит что ты секретарша с кофе для шефа,или шала...это называется SoC  

```
